# Security policy

## Reporting

Report security issues privately to **info@parallexlabs.ca**. Do not open public issues for sensitive reports.

## Scope

This lab processes text only in the browser. Expected network endpoints are `cdn.jsdelivr.net` (Transformers.js) and `huggingface.co` (optional model weights). No user text should be transmitted.

If you find code that sends pasted content elsewhere, treat it as a high-severity defect.
